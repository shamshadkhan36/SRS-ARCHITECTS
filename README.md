  - Educational Campuses

- **Interactive Project Modal**: Deep-dive project viewer with specifications, built-up area data, client briefs, and sustainable engineering highlights.
- **Location & Consultation Portal**: Office locator with direct Google Maps directions, WhatsApp chat trigger, and project consultation inquiry form.

## 🚀 Quick Start

### Direct Browser Opening
Simply open `index.html` in any web browser.

### Local Development Server
```bash
# Using Node / NPX
npx serve -l 3000 .

# Or using Python
python -m http.server 3000
```
Open `http://localhost:3000` in your browser.
